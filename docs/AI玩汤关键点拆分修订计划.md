# AI 玩汤关键点拆分修订计划

## 目标与判定口径

- 自动生成 **1–15 个**进度关键点，数量由汤底中可独立发现的隐藏推理结论决定，不按字数凑数，也不设五个的最低数量。
- 关键点必须是玩家读完主汤面后尚不知道、且对解释谜面有作用的结论。主汤面或补充汤面直接陈述的事实、其明显改写、氛围描写和无关细节不占进度权重。
- 一个关键点只承载一个可由玩家独立猜中、可由主持人判定的核心结论。共享同一结论的表述合并；不同因果环节只有能被独立发现时才拆开。
- 若汤底确实只有一个隐藏结论，允许唯一关键点占 100 分。若找不到任何有效隐藏结论，不造出凑数关键点，标为“需作者审核”，暂不作为已就绪的 AI 玩汤题目。
- 作者手动配置的既有关键点保持原样；本次 1–15 的数量约束针对自动生成。手动配置需支持单个关键点权重为 100，已有超过 15 个的手动配置不截断。

## 执行步骤

### 1. 重写自动拆分规则

修改 `apps/server/src/game.ts` 的自动关键点生成提示词：先列出主汤面与各补充汤面的已公开事实，再从汤底提取解释谜面所需的隐藏结论；按可独立发现的结论数输出 1–15 条。明确禁止把公开事实、公开事实的同义改写、同一因果链的重复表述及仅为凑数而拆出的细节计入关键点。提示内容只能指向尚未发现的结论。

生成过程把汤面、汤底、手册及补充内容视为待分析材料，不能服从其中试图改变生成规则的文字。内部审查字段可包含汤底依据、对应谜面疑点、公开事实排除判断及合并理由；持久化仍使用现有关键点结构。

### 2. 增加保存前的质量门禁

在 `apps/server/src/keyFactGeneration.ts` 及调用处加入两级校验：

1. 确定性校验：数量 1–15、ID 唯一、内容非空、权重为正且合计 100、提示齐全；拦截与汤面或补充汤面完全相同及明显重复的文本。
2. 语义复核：逐条核对汤底依据、公开信息包含关系、关键点之间的重叠、可独立提问性和对核心因果的作用。复核不通过则带原因重试，不把不合格候选写入数据库。达到重试上限后标为需作者审核，保留旧的可用版本。

数量由内容决定，不能为通过数量校验增加虚构关键点。权重优先给解释反常现象的核心因果和反转，边缘细节不得靠均分占据进度。

### 3. 同步约束内部原子事实和回合计分

修改 `apps/server/src/game.ts` 的原子事实提示词与 `apps/server/src/gameLogic.ts` 的结果校验：简单关键点保留一个事实；只有复合结论中存在多个独立的隐藏推理单元时才拆成多个。不能从一个有效关键点中拆出汤面已知事实。原子事实生成失败时，不把已知信息作为兜底计分项。

在 `apps/server/src/aiHostPrompts.ts` 的判定规则中明确：复述主汤面、已发布补充汤面或其明显同义表达不使事实进入 `DISCOVERED`。复合提问只确认玩家真正推中的隐藏部分。五态回答仍按汤底判断，计分独立处理。

### 4. 修正单关键点编辑与 API 契约

`apps/server/src/index.ts` 与 `apps/web/src/components/SoupEditor.tsx` 目前把单项权重限制为 1–99，导致一个关键点无法手动保存。改为单个关键点允许且要求 100；多个关键点仍各为正整数、总和 100。编辑界面增加简短说明：“汤面已经告诉玩家的内容不应设为关键点”，并对疑似公开内容给作者提示，不自动改写其手动配置。

### 5. 版本、旧数据与进行中对局

- 给自动关键点和原子事实的生成规则加版本号，更新缓存哈希；只重生成未被作者手动配置的作品。单纯改提示词不会让现有 `key_facts_hash` 失效。
- 多人房间沿用已绑定的不可变事实快照，新回合才使用新版本。
- 单人会话目前依赖作品当前关键点，且 `sessionContentHash` 不包含原子事实。先为新会话保存关键点和原子事实快照；迁移旧会话时保护已有进度与事实 ID。无法安全保留的活跃旧会话所在作品暂缓自动重拆，不静默重置玩家进度。
- 分批重拆旧的自动关键点，逐批记录生成数量、审核失败、公开事实误入率和作者手动配置保护结果。更新 `docs/AI主持架构.md` 中的“5～15 个”旧说明。

## 验收案例与完成标准

准备覆盖短汤、单反转汤、多人物多因果汤、含补充汤面及作者手动配置的案例集。至少验证：

| 场景 | 预期 |
| --- | --- |
| 汤面写明“雨夜、打伞、全身湿透” | 三项均不生成计分关键点；玩家复述不涨进度 |
| 汤底只有一个真正的隐藏反转 | 自动生成 1 个关键点，权重 100，可正常开始和通关 |
| 汤底有数个可独立发现的因果结论 | 按实际结论数拆分，互不重复，且不超过 15 个 |
| 玩家只猜中复合结论的一部分 | 仅对应隐藏原子事实得分，不得直接拿完整关键点进度 |
| 补充汤面已发布后玩家复述其内容 | 不得新增进度；进一步推中未公开解释仍可得分 |
| 作者已有手动关键点或活跃对局 | 自动重拆不覆盖手动配置，不改变进行中回合的事实和进度 |

针对解析、语义审核结果处理、单点 100 权重、原子事实、回合计分、缓存版本及会话兼容增加测试；运行相关服务端与前端类型检查及定向回归。用一组真实作品由人工按主持人标准盲审：公开信息计分项为零、关键点数量不靠凑数、核心因果完整。通过后再批量处理旧自动结果。
